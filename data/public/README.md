# Демонстрационный набор

Набор состоит из шести вымышленных закупок и 98 вопросов к ним. К комплекту P01 относятся 40 вопросов. Все организации и суммы выдуманы.

- `packages/P01` … `packages/P06` содержат документы в UTF-8.
- `questions.csv` содержит вопросы в формате `id;package;question`. Например, вопрос `P03-07` относится к комплекту `packages/P03`.
- `answers_public.json` содержит эталонные ответы, цитаты и категории вопросов.

Чтобы проверить P01, нажмите **Запустить тест P01** в разделе **Тестовые наборы**. [Контрольные ответы и офлайн-проверка](../p01-check/README.md).

## Формат CSV

CLI сохраняет ответы в UTF-8 с разделителем `;`.

```csv
id;status;answer;quote;file
P01-C02;ответ;Электронный аукцион.;Способ определения поставщика: электронный аукцион.;01_izveshchenie.txt
P01-C08;ответ;1 % от НМЦК.;Участник предоставляет обеспечение заявки в размере 1 % от НМЦК, что составляет 18 000,00 рублей.;01_izveshchenie.txt
```

Поддерживаемые статусы — `ответ`, `расхождение`, `нет в документах` и `не знаю`. В `quote` указывается дословная цитата длиной от 8 символов, в `file` — имя файла, из которого она взята. Числа записываются цифрами, даты — в формате `27.11.2026 10:00`, ответы на закрытые вопросы — словами «да» или «нет».

Если есть только CSV, его можно проверить напрямую из корня проекта.

```powershell
python src/evaluation/check.py answers.csv --gold data/public/answers_public.json --packages data/public/packages --out result.csv
```
